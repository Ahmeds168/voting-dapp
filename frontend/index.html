On-Chain Ballot: create and vote in polls on the Ethereum Sepolia testnet

On-Chain Ballot is a free, open-source web app, built by Ahmed Ali Shah with Solidity, Hardhat, React and ethers.js. Anyone can create a poll with a question, 2 to 20 options and a deadline, then share its link. Every vote is recorded on the Ethereum Sepolia test network, so the tally is public and cannot be edited. Results stay hidden until you vote or the poll closes, or you can choose to view them without voting.

Browsing polls needs no wallet. Creating a poll or casting a vote needs a browser wallet such as MetaMask set to Sepolia, with a little free test ETH for gas. It runs on a testnet where the ETH has no value, and each wallet address gets one vote, so someone with several wallets could vote more than once. It is a portfolio and learning project, not for binding or high-stakes elections. Source code on GitHub.
